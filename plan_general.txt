PlayDex - Planned Features
==========================

Session splitting
- Split a completed session at a chosen time; optionally assign the second part to another game.
- Divide paused intervals correctly, preserve notes and total active duration, and offer Undo.
- Validate the split lies strictly inside the original session; preserve backup/export compatibility.

Weekly rotation presets
- Save named rotations, such as Main games or Weekend co-op, including weekly targets; switching presets must still respect the weekly budget.

Merge duplicate games
- Combine two library entries while preserving sessions and personal milestones; show a preview before merging.

Bulk library editing
- Select several games to assign a platform, add or remove tags, or archive together.

Automatic playtime milestones
- Extend personal milestones with optional hour targets, such as Reach 50 hours; update progress automatically and record when the target is reached.

Session history health check
- Add a Settings tool to find existing overlaps, unusually long sessions, and sessions referencing missing games; review each issue before making corrections.
