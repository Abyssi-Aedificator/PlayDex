PlayDex - Future Feature Ideas
==============================

Features proposed but not yet implemented. Combine three proposal rounds
(the earlier 10-idea list, the 5-idea list, and the round-three list below).
Pause/Resume and the Sessions CSV export ARE implemented - left out.
The round-three streak freeze (#25) was implemented - left out.

1. Notes on sessions
   "Optional memo per session (why you stopped, what happened). Add a note
   field to the Add/Edit Session modals, show it in session rows in
   renderSessionsTab, surface the latest note on the per-game dashboard
   (renderDashboardBody)."
   - Data: optional `note` string on sessions[], old data unaffected.
   - Scope: small-medium. Risk: low. High archival value.

3. Session timeline (history view)
   "Day-grouped chronological timeline of all sessions; click a day to jump
   to that filtered view. Reuse the session-row markup + a toggle."
   - Scope: medium. Risk: low-medium.

4. Search / filter games & sessions
   "Global search box filtering both lists by text (header or top bar)."
   - Scope: small. Risk: low.

5. Yearly / all-time totals in Stats
   "Year-to-date + all-time playtime beside 'This Week' in the stat grid."
   - Scope: tiny. Risk: low.

6. Bulk session management
   "Multi-select checkboxes in the session log + delete selected."
   - Scope: medium. Risk: low-medium.

7. Session merge by time range
   "Combine a contiguous same-game range of sessions into one
   (confirm modal + duration validation)."
   - Scope: medium. Risk: medium.

8. Per-game goals
   "Optional playtime goal per game with progress on its dashboard."
   - Data: schema addition to games[] + backup payload.
   - Scope: medium. Risk: medium.

9. Idle auto-pause reminder
   "If a running session is idle / backgrounded long enough, remind to
   stop or pause (complements the manual Pause)."
   - Scope: small-medium. Risk: low-medium (pick threshold carefully).

11. Keyboard shortcuts / command palette
    "e.g. S = start/stop, G = Games tab, / = focus search; guard inputs."
    - Scope: small-medium. Risk: low.

12. Quick-start a game from the Games list
    "Inline Start button on each game row that begins the live session for that
    game and switches to the Today tab (respects the one-active-session guard)."
    - Scope: small. Risk: low.

15. Recently unlocked strip in the Player Profile
    "Show the last few badge icons with relative unlock time (e.g. '2h ago'),
    sourced from the persisted settings.achievementUnlocks timestamps."
    - Scope: small. Risk: low.

16. Background auto-backup on hide/close
    "Upload a dirty backup to Dropbox the moment the tab is hidden or closed
    (visibilitychange + beforeunload), so an unbacked session is never
    stranded behind a closed tab. Distinct from the existing auto-upload
    10s after editing."
    - Scope: small. Risk: low.

17. Merge duplicate games
    "Pick a source + target game; reassign all of the source's sessions to
    the target, port its cover and history, then archive the source. Solves
    accidental duplicate entries that rename/archive can't fix. Different from
    the planned session-range merge (plan item #7)."
    - Scope: medium. Risk: medium.

18. Merge-import backups
    "Today's JSON import replaces everything. Add a merge mode: import
    non-conflicting entries, keep the newer of conflicting ones, report
    counts (games added/skipped, sessions added). Useful for combining
    history from two devices."
    - Scope: medium. Risk: medium.

19. Per-game notes and store link
    "A short free-text note + optional URL per game, editable in the Edit
    (rename) modal, shown as a tappable link on the game dashboard. Game-level
    metadata, distinct from the proposed session notes (plan item #1)."
    - Scope: small. Risk: low.

21. Share/copy stat snapshot
    "One-tap Share (Web Share API) or clipboard-copy of a plain-text summary
    of your stats or profile, from the Stats and Profile tabs. No backend
    needed; handy for communities and social media."
    - Scope: small. Risk: low.

22. Game statuses
    "Status per game beyond archiving: Backlog / Playing / Finished / Dropped,
    with the Games tab able to filter by status."
    - Scope: small-medium. Risk: low.

23. Custom accent colour
    "Keep the preset swatches, add a free colour picker that writes any
    colour into the --accent theme variables."
    - Scope: small. Risk: low.

24. Per-game platforms & tags
    "Optional free-text tags per game ('PC', 'Switch', 'Game Pass', 'Co-op')
    with filter chips in the Games tab."
    - Scope: small. Risk: low.

26. Daily-goal streak stat
    "'Consecutive days hitting your daily goal' card in Stats/Profile,
    distinct from the raw longest play-streak."
    - Scope: tiny. Risk: low.

27. Export a stat snapshot as an image
    "Render the cumulative curve + heatmap + key numbers to a PNG (canvas)
    for sharing; complements the existing CSV export."
    - Scope: small-medium. Risk: low.

28. Sessions to calendar (.ics)
    "Export sessions as an .ics file so playtime shows up in any calendar app."
    - Scope: small. Risk: low.

29. Per-game playtime mini chart
    "30-day playtime bar/sparkline on each game's dashboard, beside the
    sessions list."
    - Scope: small. Risk: low.

30. Drag-and-drop pin ordering
    "Reorder pinned games in the quick-start list and Games tab; persist the
    manual order instead of 'pin to top' stacking."
    - Scope: small-medium. Risk: low.

31. Undo for game actions
    "Toast-undo for game archive and delete, matching the session-delete undo."
    - Scope: small. Risk: low.

--- Implementation reference notes ---
- Version markers to keep in sync on any release: .version-badge,
  APP_VERSION (~line 3915), SW_VERSION + CACHE_NAME in sw.js.
- Today/streak/stats read stored durationMs only; live-timer math uses the
  pause helpers (totalPausedMs / activeElapsedMs). New session fields are
  additive and ride through JSON backup/import and Dropbox untouched.
- CSV export already exists (Settings > Backup); reuse triggerDownload().
- Commit policy: one feature per commit, no version numbers in messages,
  no version bump unless asked; changelog bullets go under the current
  Version header.
