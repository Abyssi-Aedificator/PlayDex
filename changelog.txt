PlayDex - Changelog
====================

Version 1.5.1
-------------------
- Settings are no longer synced to Dropbox; they remain device-local. Manual exports still include all settings for full backups.

Version 1.5.0
-------------------
- The Last 6 months bars in a game's dashboard now fill to show each month's playtime.
- A paused timer is now obvious at a glance: the live card turns amber, shows a PAUSED badge, and dims the clock while it's held.
- While a session is paused, the live card shows how long the timer has been paused, and the pause time also appears in the browser tab title.
- The LIVE and PAUSED labels on the timer card are now easy to read in the light theme, where they previously blended into the pale background.
- PlayDex now shows a loading screen with the app logo that stays up for a few seconds while it starts up.
- The app no longer flashes the dark theme before your chosen light theme loads.
- Theme Colour has a new Grey option that stays readable in both the light and dark themes.
- The + Add button on the Sessions tab no longer spills outside the card when the screen is narrow.
- The startup loading screen is now shorter, staying up for 1 to 3 seconds.
- When the filter row is narrow, the All/Synced/Unsynced control now stays with the + Add button instead of leaving it on a line of its own.
- Settings has a new Interface choice. Pick Material 3 for a Google Material Design look, or keep Classic.
- Material 3 restyles the whole app with tonal colour, rounded shapes, floating field labels, switches and cards, and gives the Today tab a floating Log session button.
- The Material 3 interface follows your Theme and Theme Colour choices, so your accent still drives the palette.
- Material 3 notification banners now wrap onto several lines and stay above
  the Log session button instead of running off the screen or covering it.
- Material 3 buttons, tabs and options now show a soft highlight when you point
  at or press them, instead of changing colour or lifting, and cards no longer
  pick up a shadow when you point at them.
- Material 3 screens now transition in smoothly with the Material easing curve
  instead of the old fade.
- Material 3 headings, numbers and card titles now use the sizes and weights of
  the Material type scale, and the supporting colour is much softer so it no
  longer looks like a second copy of your main colour.
- On wide screens the Material 3 Log session button now shows its label as well
  as the icon; on narrow phones it collapses to just the icon.

Version 1.4.0
-------------------
- The Profile playtime curve now rolls up by month for very long histories instead of breaking.
- Deleting or undoing a session now updates every tab instantly, and pinning a game reorders the quick-start list on Today.
- Importing a backup no longer resets your accent color.
- The Last 7 Days card in Stats now scopes Most Played, Avg Session, and Total Sessions to the current week instead of all time.
- The Games list now shows when each game was last played as a relative time, like '36d ago', instead of the absolute date.
- The Manage Games list on the Games tab is now a little wider on desktop screens.
- A play streak now survives one missed day: earn a freeze for each week of daily play, up to 3, shown as a snowflake on the Stats review card.
- Per-game tags: add comma-separated labels to a game from its Edit dialog, see them as chips in the Games list, and click a tag to filter the list.
- If a running session is left idle for a while, PlayDex now asks whether to keep going, pause, or stop (optional, off by default in Settings).
- Keyboard shortcuts: press S to start/stop, G/T/H/A/B/P/C to jump between tabs, / to focus the Games search, and Esc to close a dialog.
- Archiving or deleting a game now offers a one-tap Undo in the toast, restoring the game and — for deletes — its sessions.
- Each game's dashboard now shows a 30-day playtime mini chart alongside the monthly bars and recent sessions.
- The Today tab's Start a Game list is back to just the game name and a play icon — removed the per-game tags, last-played time, and Play again? tag.
- Start a session straight from the Games tab: a play button on each game row begins the live timer and takes you to Today.
- A "What should I play?" button on the Today and Games tabs suggests a game at random (or the least-played one), with one-tap start and re-roll.
- Added a red option to the Theme Colour swatches in Settings.
- New Top tab showing games sorted by most played this week, with a trend arrow (↑/↓) or dash showing each game's position last week and a NEW badge for games not played last week.
- The Top tab uses a wider layout on desktop.
- Top tab: pick the period to rank by - This week, the last 7 days, the current month, or all time - and the trend compares against the previous equal period.
- The Top tab now shows the period's total playtime, how it changed against the previous period, and the number of sessions.
- Each game row in the Top tab shows how much more or less you played it compared with the previous period.
- The top three games in the Top tab are marked with medals.
- The Top tab shows a "Fell out" section for games that were on the previous period's list but have no playtime in the current one.
- The current number-one game in the Top tab is marked when it has held the top spot for several weeks in a row.
- Each game in the Top tab shows a small bar chart of when it was played during the period.

Version 1.3.0
-------------------
- Switching tabs brings you back to the top of the app.
- The Quests card shows the weekly board once all of today's quests are done.
- Find games fast with a search bar in the Games tab.
- The Profile page stacks Next Badge and Favorite Game compactly beside Personal Records, with Playstyle on its own full-width row.
- Pin your favourite games to the top of the Games tab and the quick-start list.
- Session rows and game dashboards now show how many times a session was paused and for how long.
- The running session shows in the browser tab title and can send a system notification when a target is reached.
- The Profile page shows a cumulative playtime curve over all your sessions.
- Games without a cover are flagged in the Games tab.
- The Stats tab gets a this-week review card: total time, sessions, top game, best day, and play-streak, with a comparison against last week.
- The Profile page shows a time-of-day heatmap of when you usually play.
- The Profile milestone timeline gains 200- and 500-session marks, a 250-hour total, and a 30-day play-streak milestone.
- Games you haven't played in 7, 14, or 30 days get a subtle 'Play again?' highlight in the Games list, with an optional Today-tab prompt to revisit them.

Version 1.2.0
-------------------
- The live session timer can be paused and resumed, shows the session start
  time and the current time in 24-hour format beside the running elapsed
  time, and tells you how long until your next playtime badge.
- Set an optional time target when starting a session, watch progress toward
  it on the timer card, and your phone buzzes with a confirmation message
  when your session reaches it.
- Deleted sessions can be undone from the confirmation toast, and completed
  sessions can be exported to CSV from Settings.
- The Games list shows when each game was last played and how often.
- A new Badges tab tracks milestone achievements, play streaks, and a player
  level earned from your play history; badge cards show their rarity tier, a
  freshly unlocked badge glows for 24 hours, earned badges show their unlock
  date, and they flow into multiple columns on wide screens.
- Badge unlocks trigger celebrations on the spot — and never repeat one you
  have already seen — while your phone buzzes when you unlock a badge or
  level up, and you earn XP for time played.
- Locked badges estimate how long until you can earn them from your average
  weekly play, stay on one line even on narrow cards, and their estimates
  hold up in any timezone.
- Daily and weekly quest boards with XP rewards keep the level meter moving,
  quests are drawn at random (five new each day and each Monday), the Quests
  card counts what you have completed and when it resets, daily streaks and
  a Weekly Champion banner reward full completions — and the profile shows
  your achievement XP (with a share of the maximum) and XP remaining to the
  next level.
- 14 new badges extend Game Variety, Epic Sessions, and Dedication with
  game-count ladders, 3- and 8-hour sessions, single-day play and session
  records, day-count milestones, and early-bird and night-owl chains.
- A new Profile tab introduces your player record: a custom name, badge
  count and XP, playtime and streak totals, and a progress ring of overall
  badge completion; set your name, see which badge unlocks next, and jump to
  your favorite game.
- The profile splits your sessions into a playstyle bar (Quick, Standard,
  Marathon) and charts your playtimes by weekday.
- A weekly streak calendar shows the past 52 weeks, with a milestone timeline
  for firsts and totals; your longest streak counts the weeks you played, and
  month labels swap in or out automatically so the grid stays uniform on any
  screen.
- Review sessions you haven't marked as synced: filter the list by sync
  status, see every unsynced entry across all dates with a running total of
  remaining time, and mark them all synced in one tap (with undo); filtered
  rows also show each session's date and that day's total.
- Your profile's longest session record names the game it was played on, and
  a game's session history shows the last 5 sessions instead of 10.
- Give a game a cover image — upload a picture or paste an image URL, manage
  it from the game's Edit screen, and see it on the game's stats page; while
  a session runs, the live timer fades its game's cover behind a subtle
  backdrop with the next-badge hint in dimmed white.
- Game stats (the game dashboard) open reliably again, long stats dialogs
  scroll so their Close button is always reachable, URL covers stay editable
  in the Edit screen, and the pending-sync banner no longer grabs taps while
  hidden.

Version 1.1.0
-------------------
- Added full PWA support (manifest, service worker, installable icons) with an
  Install app button, and scoped the app so it no longer collides with other
  apps on the same GitHub Pages origin.
- Fixed the service worker so it only manages PlayDex's own caches and reliably
  installs the corrected, origin-safe worker across existing installs.
- Replaced the native time inputs in the Add/Edit Session modals with a themed
  AM/PM time picker and fixed the HH/MM field sizing.
- Stopped the whole session list from re-animating when you mark a session
  Synced or Deleted, and removed the "Quick add game" field.
- Added a themed messagebox that notifies you when a new version of PlayDex is
  available and ready to install, with a "Reload now" action that shows once
  per version.
- Added a Theme Colour picker in Settings so you can change the app's accent
  colour, applied instantly across buttons, tabs, calendar and highlights.
- On wider screens, the Today and Sessions tabs are combined into a single
  page: today's overview on the left and the session list on the right, with
  the separate Sessions tab hidden.
- Added a "Last 30 Days" playtime graph to the Stats tab and, on wide PC
  screens, showed Stats as a third column in the combined Today page.
- Kept the theme colour (accent) device-local so it is no longer synced or
  overwritten through Dropbox.
- Widened the combined desktop page and gave Today and Sessions slightly more
  room than Stats.
- Listed the Games tab and the Playtime by Game breakdown alphabetically, and
  sorted the Start a Game list on the Today page by most recently played.
- Today's bar in the Last 7 Days chart now matches the accent colour of the
  other bars.
- Starting a game now scrolls you back to the top so the live timer is in view.
- On a filtered date, each session shows that game's total playtime for the day
  in pale accent text next to its own duration.
- Games with unsynced time now show their name in red in the Playtime by Game
  list.
- Added a sync button in the header with a warning dot, and a reminder banner
  with a Sync now shortcut, a dismiss button, and an option to hide it, shown
  when changes haven't been backed up to Dropbox yet.

Version 1.0.0
----------------
- Initial release.
- Track game sessions with live elapsed time and start/stop control.
- Session log with start/end times, durations, and per-session sync toggles.
- Playtime by game breakdown (synced vs. not-synced).
- Daily playtime goal with a progress tracker.
- Game library with add, edit, and archive support.
- Dropbox sync for backing up and sharing data across devices.
- Dark and light themes.
