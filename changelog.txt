PlayDex - Changelog
====================

Version 1.8.4
-------------------
- Renamed How Long to Beat to HLTB and added Games badges for missing or unavailable estimates. Set HLTB to Not needed for this game to hide the missing-estimate badge.

Version 1.8.3
-------------------
- Added Games dropdown filters for pin status, cover art, HLTB status, personal milestones, weekly rotation, and play history.
- Added optional How Long to Beat estimates for Main Story and Main + Extra with optional previously played hours and progress bars in the game dashboard and Session saved popup.
- Assign weekly rotation games to weekdays or Any day and review planned hours by day against the weekly budget. Today shows only games planned for the current day and Any day games. The rotation editor is wider on larger screens.
- Estimate unfinished milestone dates from optional hours remaining and the last four full weeks of playtime.
- Review active and paused time, goal progress, and sync status immediately after stopping a session. Marking it synced keeps the review buttons in place.
- Browse daily playtime in a Stats calendar with a daily total, grouped game and session rows, and a shortcut to open the selected date in Sessions.
- Added a wider startup review of unsynced completed sessions with individual, per-game, and Mark all synced actions, with a compact theme-coloured badge showing each game's daily total across synced and unsynced sessions.
- Kept Mark synced buttons inside the startup review list when hovering, preventing a horizontal scrollbar.
- Added a Review unsynced button in Sessions. The popup closes automatically after the last session is marked synced.

Version 1.8.2
-------------------
- Dropbox now syncs settings including weekly rotation games and targets, while Theme, Interface, and Theme Colour stay on each device.

Version 1.8.1
-------------------
- Added Settings > Playtime goal > Automatically use last week's daily average; the daily goal updates automatically and the weekly rotation budget is seven times that goal.
- Fixed Liquid Glass session sync filters so the Unsynced label fits inside its segment.
- Liquid Glass panels are more translucent, with stronger backdrop blur, soft reflective highlights, and brighter glass edges while preserving accessibility fallbacks.
- Renamed the Apple interface option to Liquid Glass.
- Liquid Glass theme-coloured backgrounds drift gently in a 24-second loop, pause while the app is hidden, and stay static when the system requests reduced motion.
- Today's Goal shows Daily average (last week) for the previous calendar week, rounded to the nearest whole hour, following Week starts on and including days with no sessions.
- Automatic goals disable manual editing; turning the option off restores the saved manual goal, and changes that would put the weekly rotation over budget are blocked.
- Liquid Glass uses a background drawn from the selected Theme Colour and semi-transparent frosted panels, with opaque fallbacks for Reduce transparency and Increase contrast.
- Liquid Glass Increase contrast uses the selected Theme Colour for stronger borders and the selected navigation item, with readable contrasting text.
- Removed the Liquid Glass Reduce motion switch; system reduced-motion preferences continue to apply automatically.
- Refined the Liquid Glass interface around Liquid Glass principles: neutral glass navigation with layered highlights and progressive edge refraction, a moving selection lens, scroll-edge separation, capsule controls, and adaptive sheets and popovers.
- Liquid Glass display options follow system accessibility preferences and provide additional Reduce transparency and Increase contrast controls.
- Added an Apple-inspired Liquid Glass interface with grouped light and dark surfaces, system typography, translucent floating navigation, rounded controls, and accessible theme-colour accents.
- Interface selection persists across launches; switching among Classic, Material 3, and Liquid Glass keeps the selected theme colour and existing data.

Version 1.8.0
-------------------
- Added spacing between the game name and tags fields in the Classic Edit Game dialog.
- Games has a No platform selected filter with a count, combining with search and tags to find games missing a console or PC assignment.
- Games has a right-side filter panel for platform, missing platform, active or archived games, pinned games, and tags, with a result count and Clear filters; it stacks above the list on smaller screens.
- Archived games offer Edit when either their cover or platform is missing; Edit disappears once both are filled in.
- Widened the Games filter panel for easier use on larger screens.
- Settings groups controls under Appearance, Session tracking, Dropbox, and Data, with section navigation and visually separated data-maintenance actions.
- Top replaces its permanent ranking legend with an expandable guide and clearer movement badges.
- Games filters collapse on smaller screens, show an active-filter count, and provide removable filter chips above results.
- Sessions are grouped by date with daily totals for the current filters and simpler individual rows.
- Game library rows show square cover thumbnails with themed placeholders and platform badges.
- Today's Goal calculates a weekly goal of seven times the daily goal; weekly rotation shows planned and available time and limits combined targets to that budget.
- Weekly rotation and its editor show a progress bar for the unallocated weekly time, updating as targets change.
- Weekly rotation targets use whole-hour input; existing partial targets round up in the editor and change only when saved.
- Saving an over-budget rotation displays how much time to remove and the maximum allowed total, keeping the editor open for corrections.
- Daily playtime goals use whole-hour input, with budget checks showing the minimum daily goal required to cover saved rotation targets.
- Weekly rotation allows any number of games, with combined targets still limited by the weekly time budget.
- Games you haven't played in a while excludes weekly rotation games and no longer has a dismiss button.
- Material game filters open as a bottom sheet on compact screens; the bundled font is cached for offline use.
- Material buttons, chips, checkboxes, settings, lists, charts, and dialogs share consistent sizing, focus states, hierarchy, and reduced-motion support.
- Material mode has accessible themed select menus, date-picker dialogs, and dial or keyboard time entry with confirmation and cancellation.
- Material navigation keeps every destination, uses two rows below 600px, and positions content, the FAB, and snackbars around the actual navigation height.
- Material mode now uses HCT-generated light and dark palettes, bundled Roboto Flex typography, Material Symbols, and expressive tonal surfaces.
- During a running or paused session, rotation shows only the current rotation game, hides Start and Playing actions and budget details, and updates progress using active playtime; the card is hidden for games outside the rotation.
- Rotation progress uses compact elapsed and target durations, a distinct percentage badge, and a progress bar without duplicate played-status text.
- Stale-game reminders replace rotation exclusions with the next available non-rotation games, including never-played games, to show up to three suggestions.
- Weekly rotation and daily goal progress use whole-minute precision and refresh as live playtime reaches each minute; the main session timer retains seconds.
- Added personal game milestones with named checkpoints, editable completion dates, and actions to complete, reopen, edit, or delete them from each game dashboard.
- Game dashboards use a wider two-column layout on larger screens, with milestones beside stats and history.
- Session rows show each game's combined playtime for the session date in a subtle label using the selected theme colour.
- Archiving a weekly rotation game releases its unused target time back to Available time, while its completed playtime stays counted for the current week; rotation and daily-goal budget checks use the same calculation.
- Starting a game resets the Target selection to Off and clears custom minutes, while preserving the chosen target on the new session.
- Classic goal, rotation, and milestone progress bars share rounded styling and values above the bars; archived games keep readable artwork and use an Archived label instead of crossed-out names.
- Classic uses clearer card headings, a theme-coloured selected-tab background, and consistently sized secondary actions with separated Delete buttons.
- The target-reached Got it button works even when service workers are unavailable.
- Material dialogs keep keyboard focus inside the topmost dialog, including milestone editors opened over a game dashboard.
- Restoring or undoing the archive of a rotation game is blocked with an explanation when its restored target would exceed the weekly budget.
- Invalid backup records are rejected before replacing local data during manual import, Dropbox download, or rollback.

Version 1.7.0
-------------------
- Added a Daily goal streak stat showing consecutive days hitting your daily goal.
- Settings offers Sunday or Monday as the first day of the week; calendar pickers, week-based charts, streaks, and resets follow the setting.
- Moved This Week Review above Last 7 Days in Stats.
- Dropbox sync detects conflicting backups, protects pending local changes from automatic replacement, and saves an exportable recovery copy before downloading history.
- Existing Dropbox connections can establish their sync revision without replacing matching local history.
- Editing sessions preserves paused time and unchanged seconds; pause records are trimmed to the edited session times.
- Open tabs refresh when another tab changes stored data, and stale saves are blocked to protect newer history.
- The bottom navigation stays in place when switching between tabs with and without a page scrollbar.
- Sessions can be filtered by game, inclusive date range, and sync status, with matching totals, Clear filters, and filtered CSV export.
- Session filters have aligned labeled fields, a separate Add session button, responsive actions, and matching From and To calendars.
- Removed game statuses from the library and Edit Game dialog.
- Top shows each game's share of playtime and the time gap to the next rank, labels ties, and opens game dashboards from ranking and Fell out entries.
- Top supports custom From/To dates using the Sessions calendar controls, with comparison against the preceding equal-length date range.
- Top can include archived games in rankings, totals, shares, trends, and historical comparisons through a theme-matched switch.
- Game action buttons stay inside their highlighted row and wrap safely on narrow screens.
- Dropbox keeps a live file and its five previous changes, with dated version history and confirmed rollback in Settings; rollback preserves the previous live version and a local recovery copy.
- App updates wait for Update now confirmation; Later keeps the approved version and offers the pending update again when the app reopens.
- What should I play uses the suggested game's artwork as the dialog background, stretched to fill it, with a readable theme-aware overlay and a fallback for games without covers.
- Fixed question marks appearing instead of date separators in the Top custom-range description.
- Replaced app icons with the orange folded P across browser tabs, installed apps, the header, and the loading screen; the header uses the icon as the first letter of PlayDex.
- The default Theme Colour is Orange to Red; saved colour choices are preserved.
- Adding or editing an overlapping session warns before saving, with Cancel and Keep both choices.
- Stats compares two games by total playtime, session count, average length, recent activity, and last played.
- Stats offers monthly and yearly recaps with top games, first-time games, busiest day, and comparison with the previous period.
- Stats stays available as its own desktop tab, with cards flowing independently in two columns; Today uses two equal columns with the same maximum width as Profile.
- Desktop tabs are ordered Today, Stats, Top, Games, Badges, Profile, Settings; mobile retains Sessions after Today.
- Top includes Biggest movers, a cover-art podium, Most consistent games, New discoveries, and a playtime distribution chart, following the selected period and archived-games filter.
- Top insight cards flank the ranking on wide desktops and stack below it on smaller screens; podium covers fill square thumbnails without empty bars.
- Classic has a theme-matched splash screen with the orange P wordmark and subtle progress motion; Material 3 has its own tonal design, rounded icon container, typography, and progress motion.
- The splash screen stays visible for a random 2-5 seconds, respects reduced motion, and has no decorative dot beside the loading label.
- What should I play suggests games for 15, 30, or 60 minutes using typical lengths from recent completed sessions, alongside Random and Least played modes.
- Settings automatically loads Dropbox version history whenever the tab opens, including after a running sync finishes.
- Sessions can record PC, PlayStation, Xbox, or Nintendo; Stats shows playtime by platform, and CSV and backups preserve the choice.
- Edit Game has a platform selector beside Remove cover to set the default for future sessions; Today's full-width Platform selector filters the active game list, with All platforms showing every active game.
- Today has a device-local weekly rotation of up to five games, with one-tap start, optional weekly playtime targets, and progress from completed sessions following Week starts on.
- Games disappear from the rotation after reaching their weekly target and return next week with their selection and target preserved; Choose games identifies reached targets and updates progress when targets are edited.
- The weekly rotation editor is 540px wide on larger screens, with room for game names, progress, and target inputs.
- Today's Goal sits below This week's rotation and above Start a Game; Total Playtime Today sits above Sessions on desktop and shows only total time and session count.
- What should I play sits directly below the Platform selector in Start a Game.
- Removed session notes from Add/Edit Session, history, and CSV exports, along with latest-note previews beside start actions.
- Removed the platform playtime breakdown from individual game dashboards.

-------------------
- Settings are no longer synced to Dropbox; they remain device-local. Manual exports still include all settings for full backups.
- New app icons.
- In the Classic interface, the background follows your Theme Colour, so the corner glow and drifting background match your chosen accent instead of staying violet and cyan.

- A new loading screen with an animated logo, progress bar and dots.
- New app icon — a game controller on a dark tile — used for the tab, home screen and install.
- The loading-screen logo follows your Theme Colour from the first frame, with no violet flash while the app starts.
- Pause display now shows total paused time plus the current pause when resuming for a second time, and only the current pause on the first pause.
- Smoother animations and transitions across the app, following Material 3 motion guidelines.

- PlayDex now shows a loading screen with the app logo that stays up for a few seconds while it starts up.
- The app no longer flashes the dark theme before your chosen light theme loads.
- Theme Colour has a new Grey option that stays readable in both the light and dark themes.
- The + Add button on the Sessions tab no longer spills outside the card when the screen is narrow.

- When the filter row is narrow, the All/Synced/Unsynced control now stays with the + Add button instead of leaving it on a line of its own.
- Settings has a new Interface choice. Pick Material 3 for a Google Material Design look, or keep Classic.
- Material 3 restyles the whole app with tonal colour, rounded shapes, floating field labels, switches and cards, and gives the Today tab a floating Log session button.

- Material 3 screens now transition in smoothly with the Material easing curve instead of the old fade.

Version 1.4.0
-------------------
- The Profile playtime curve now rolls up by month for very long histories instead of breaking.
- Deleting or undoing a session now updates every tab instantly, and pinning a game reorders the quick-start list on Today.
- Importing a backup no longer resets your accent color.
- The Last 7 Days card in Stats now scopes Most Played, Avg Session, and Total Sessions to the current week instead of all time.
- The Games list now shows when each game was last played as a relative time, like '36d ago', instead of the absolute date.
- The Manage Games list on the Games tab is now a little wider on desktop screens.
- A play streak now survives one missed day: earn a freeze for each week of daily play, up to 3, shown as a snowflake on the Stats review card.
- Per-game tags: add comma-separated labels to a game from its Edit dialog, see them as chips in the Games list, and click a tag to filter the list.
- If a running session is left idle for a while, PlayDex now asks whether to keep going, pause, or stop (optional, off by default in Settings).
- Keyboard shortcuts: press S to start/stop, G/T/H/A/B/P/C to jump between tabs, / to focus the Games search, and Esc to close a dialog.
- Archiving or deleting a game now offers a one-tap Undo in the toast, restoring the game and — for deletes — its sessions.
- Each game's dashboard now shows a 30-day playtime mini chart alongside the monthly bars and recent sessions.
- The Today tab's Start a Game list is back to just the game name and a play icon — removed the per-game tags, last-played time, and Play again? tag.
- Start a session straight from the Games tab: a play button on each game row begins the live timer and takes you to Today.
- A "What should I play?" button on the Today and Games tabs suggests a game at random (or the least-played one), with one-tap start and re-roll.
- Added a red option to the Theme Colour swatches in Settings.
- New Top tab showing games sorted by most played this week, with a trend arrow (↑/↓) or dash showing each game's position last week and a NEW badge for games not played last week.
- The Top tab uses a wider layout on desktop.
- Top tab: pick the period to rank by - This week, the last 7 days, the current month, or all time - and the trend compares against the previous equal period.
- The Top tab now shows the period's total playtime, how it changed against the previous period, and the number of sessions.
- Each game row in the Top tab shows how much more or less you played it compared with the previous period.
- The top three games in the Top tab are marked with medals.
- The Top tab shows a "Fell out" section for games that were on the previous period's list but have no playtime in the current one.
- The current number-one game in the Top tab is marked when it has held the top spot for several weeks in a row.
- Each game in the Top tab shows a small bar chart of when it was played during the period.

Version 1.2.0
-------------------
- The live session timer can be paused and resumed, shows the session start time and the current time in 24-hour format beside the running elapsed time, and tells you how long until your next playtime badge.
- Set an optional time target when starting a session, watch progress toward it on the timer card, and your phone buzzes with a confirmation message when your session reaches it.
- Deleted sessions can be undone from the confirmation toast, and completed sessions can be exported to CSV from Settings.
- The Games list shows when each game was last played and how often.
- A new Badges tab tracks milestone achievements, play streaks, and a player level earned from your play history; badge cards show their rarity tier, a freshly unlocked badge glows for 24 hours, earned badges show their unlock date, and they flow into multiple columns on wide screens.
- Badge unlocks trigger celebrations on the spot — and never repeat one you have already seen — while your phone buzzes when you unlock a badge or level up, and you earn XP for time played.
- Locked badges estimate how long until you can earn them from your average weekly play, stay on one line even on narrow cards, and their estimates hold up in any timezone.
- Daily and weekly quest boards with XP rewards keep the level meter moving, quests are drawn at random (five new each day and each Monday), the Quests card counts what you have completed and when it resets, daily streaks and a Weekly Champion banner reward full completions — and the profile shows your achievement XP (with a share of the maximum) and XP remaining to the next level.
- 14 new badges extend Game Variety, Epic Sessions, and Dedication with game-count ladders, 3- and 8-hour sessions, single-day play and session records, day-count milestones, and early-bird and night-owl chains.
- A new Profile tab introduces your player record: a custom name, badge count and XP, playtime and streak totals, and a progress ring of overall badge completion; set your name, see which badge unlocks next, and jump to your favorite game.
- The profile splits your sessions into a playstyle bar (Quick, Standard, Marathon) and charts your playtimes by weekday.
- A weekly streak calendar shows the past 52 weeks, with a milestone timeline for firsts and totals; your longest streak counts the weeks you played, and month labels swap in or out automatically so the grid stays uniform on any screen.
- Review sessions you haven't marked as synced: filter the list by sync status, see every unsynced entry across all dates with a running total of remaining time, and mark them all synced in one tap (with undo); filtered rows also show each session's date and that day's total.
- Your profile's longest session record names the game it was played on, and a game's session history shows the last 5 sessions instead of 10.
- Give a game a cover image — upload a picture or paste an image URL, manage it from the game's Edit screen, and see it on the game's stats page; while a session runs, the live timer fades its game's cover behind a subtle backdrop with the next-badge hint in dimmed white.
- Game stats (the game dashboard) open reliably again, long stats dialogs scroll so their Close button is always reachable, URL covers stay editable in the Edit screen, and the pending-sync banner no longer grabs taps while hidden.

Version 1.1.0
-------------------
- Added full PWA support (manifest, service worker, installable icons) with an Install app button, and scoped the app so it no longer collides with other apps on the same GitHub Pages origin.
- Fixed the service worker so it only manages PlayDex's own caches and reliably installs the corrected, origin-safe worker across existing installs.
- Replaced the native time inputs in the Add/Edit Session modals with a themed AM/PM time picker and fixed the HH/MM field sizing.
- Stopped the whole session list from re-animating when you mark a session Synced or Deleted, and removed the "Quick add game" field.
- Added a themed messagebox that notifies you when a new version of PlayDex is available and ready to install, with a "Reload now" action that shows once per version.
- Added a Theme Colour picker in Settings so you can change the app's accent colour, applied instantly across buttons, tabs, calendar and highlights.
- On wider screens, the Today and Sessions tabs are combined into a single page: today's overview on the left and the session list on the right, with the separate Sessions tab hidden.
- Added a "Last 30 Days" playtime graph to the Stats tab and, on wide PC screens, showed Stats as a third column in the combined Today page.
- Kept the theme colour (accent) device-local so it is no longer synced or overwritten through Dropbox.
- Widened the combined desktop page and gave Today and Sessions slightly more room than Stats.
- Listed the Games tab and the Playtime by Game breakdown alphabetically, and sorted the Start a Game list on the Today page by most recently played.
- Today's bar in the Last 7 Days chart now matches the accent colour of the other bars.
- Starting a game now scrolls you back to the top so the live timer is in view.
- On a filtered date, each session shows that game's total playtime for the day in pale accent text next to its own duration.
- Games with unsynced time now show their name in red in the Playtime by Game list.
- Added a sync button in the header with a warning dot, and a reminder banner with a Sync now shortcut, a dismiss button, and an option to hide it, shown when changes haven't been backed up to Dropbox yet.
